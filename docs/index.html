AgentTab × x402: pay-per-call FX API on Celo

An AI agent buys USD/BRL quotes on two stablecoin rails: x402 exact (EIP-3009, gasless for the buyer, settled by Celo's hosted facilitator per call) and an AgentTab channel (one deposit, an EIP-712 voucher per call, batched onchain settlement). Built for the Celo Agents on Open Rails hackathon, track Open Corridors · USA₮ with x402.

This page is a static replay of a real Celo mainnet run recorded on 2026-10-15 (every tx link below is live on Celoscan). The interactive version runs locally with scripts/local-demo.sh; it needs a provider process, so it is not hosted here. That run settled in USD₮. A scoring USA₮ mainnet run on 2026-10-17 carries official ERC-8021 tag celo_f4012694135b (table below). ERC-8004 Agent ID: 9965.

How it works

agent ──GET /x402/quote──▶ provider ──402 (price, rails)──▶ agent
  ├─ x402:     sign EIP-3009 ─▶ provider ─▶ Celo facilitator /verify + /settle ─▶ stablecoin transfer onchain
  └─ AgentTab: open(deposit) once ─▶ N × signed vouchers (off-chain) ─▶ provider settle() every N calls
